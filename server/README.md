# 黑猫SCRM 服务器

客户登录（没有注册）、配套与 AI 点数、Claude 中转扣点、管理后台。只需要 Node.js 22.13 以上，不需要安装其他套件。

## 第一次运行

```bash
cd server
npm run setup
```

会建立管理员密码和一个「无限使用」ID（默认用户名 `blackcat-owner`），密码写在 `data/initial-credentials.txt`。登录后台改密码后删掉这个文件。

## 启动

```bash
ANTHROPIC_API_KEY=你的Key PORT=8787 npm start
```

- 管理后台：`http://服务器地址:8787/admin/`
- 正式上线请放在 HTTPS 后面（例如 Caddy / Nginx 反向代理），并设 `ADMIN_COOKIE_SECURE=1`。
- 资料都在 `data/blackcat.db`，请定期备份这个文件。
- `ANTHROPIC_API_KEY` 只在服务器上读取，不会传给客户，也不会显示在后台。

## 环境变量

| 变量 | 说明 |
|---|---|
| `ANTHROPIC_API_KEY` | 你的 Claude API Key，客户用黑猫点数时由服务器代为调用 |
| `PORT` | 端口，默认 8787 |
| `DATA_DIR` | 资料目录，默认 `./data` |
| `DIST_DIR` | 发布更新时读取安装包的文件夹，默认 `../dist` |
| `ADMIN_COOKIE_SECURE` | 用 HTTPS 时设为 `1` |

## 点数怎么扣

扣点 = 实际 Claude 费用（美元）× 1000 × 倍率（后台 → 设置）。先扣配套点数，再扣充值/分配的点数。配套点数按每位客户自己的开通日期每月重置；分配的点数不会过期。「无限使用」账号会记录用量，但不扣点。

## 推送软件更新

1. 在项目的 `package.json` 把 `version` 调高（例如 1.14.0 → 1.14.1）。
2. 在项目文件夹运行 `npm run dist`，新安装包会在 `dist` 里。
3. 打开管理后台 → **软件更新**，写更新说明，点「发布 v1.14.1」。
   - 勾选「强制更新」：旧版本会被挡住，必须更新后才能继续用。
4. 客户的软件会在打开 20 秒后、之后每 3 小时检查一次，在后台下载好，然后提示「重启更新」；客户也可以在 设置 → 常规 → 软件更新 手动检查。没点重启的话，下次关闭软件时也会自动装好。

安装包放在 `data/updates/`（只保留最新两个版本），下载地址 `/updates/latest.yml` 和 `/updates/<安装包>` 是公开的（没有账号登录也用不了软件）。
「客户电脑上的版本」显示最近 30 天每个版本有几台电脑在用。

**最简单的方法：** 双击项目文件夹里的 `推送更新.bat`，输入更新说明，选是否强制更新，它会自动调高版本号、打包、发布。
