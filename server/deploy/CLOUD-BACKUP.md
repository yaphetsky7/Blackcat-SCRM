# R2 云备份（1.16.0）

Business 每个黑猫客户账号共用 100 GB；Enterprise 共用 500 GB。Starter / Pro 保留本地备份。多台电脑共用配套容量，各自拥有恢复点；以十进制 GB 计。AI 无限点数不代表无限云空间。

## 开通

1. 在 Cloudflare 完成 R2 开通，创建专用、私有、Standard bucket，例如 `blackcat-cloud-backups`。不要开启 r2.dev 或公开域名访问。
2. 为此 bucket 创建仅限该 bucket 的 Object Read & Write S3 凭据。不要使用账户管理级权限。凭据仅在终端输入，禁止放入客户端、截图、聊天、Git 或网站。
3. 服务器更新到此版本，包含根目录 `cloud-format.js`、server 目录全部源码，服务引用 `/etc/blackcat-server/r2.env`。
4. root 手动执行 `blackcat-configure-r2`。它会隐藏读取凭据、用随机测试对象验证写/读/删除，成功后才启用配置。配置权限 0600。
5. 在软件「设置 → 云备份」手动备份一次，再用另一个电脑下载并导入，核对对话、附件和业务资料。

## 初期额度保护

默认此服务总存量上限 9,000,000,000 bytes，含上传中预留、未引用文件及恢复点索引；低于 R2 账户免费 10 GB。所有客户共享这个试用保护。单个配套仍显示 100/500 GB，但试用保护先于配套额度生效。

服务每月最多尝试 800,000 次 Class A / 8,000,000 次 Class B 操作。标准免费额度为整个 Cloudflare 账户共享，不是每 bucket 或每客户。其他 bucket、控制台、手动工具的请求不在此计数；不能据此保证整个 Cloudflare 账户绝无费用。Cloudflare 的免费额度不是硬封顶，正式开放 100/500 GB 前，业主需决定提高 R2_TOTAL_LIMIT_BYTES 并承担实际用量账单。此版本不会自动放宽限制。

## 保存与恢复

- 4 MiB SHA-256 分块、同一客户内部去重、失败可重试。服务先预留容量，再上传；恢复时验证每块、整个文件大小和摘要。
- 归档 SQLite 用一致性快照。仅备份已经保存到本地的消息和附件；网页未加载或没有下载的原影片不能由云备份补全。
- 包含备注、联系人/账号联系人缓存、知识库源文件及学习结果、群发模板及名单、关联的快捷回复媒体。知识库学习结果直接恢复，不重复调用 Sonnet 学习。
- 不保存平台 cookies、平台登录、代理密码、黑猫登录 token、Claude / 转写 API 密钥。知识库 API 连接凭据排除；学习内容保留，需重新填写连接凭据才能刷新来源。
- 每台电脑保留最近 24 个恢复点；每客户总计最多 100 个。到达总数时暂停，管理员/客户可删除旧恢复点。当前配套到期/停用时云 API 不开放，续费后可继续；降级到 Pro/Starter 仍可下载/删除自己的已有恢复点，但不能新增。
- 未引用分块和索引至少保留一天，防止其他电脑正在上传；上传前和手动清理会回收。删除恢复点不删除本地资料；空间不会立刻下降。
- 下载到用户选择位置的新文件夹，完成后可在黑猫只读查看对话。导入需要保存工作并重开软件；现有本地资料优先保留。账号按平台+号码/username 匹配；可新增未登录入口。AI 回复不自动开启、群发任务不恢复执行。
- 原资料另存 userData/cloud-restore-originals/恢复点ID。原本已配置的本地聊天归档路径不覆盖；新电脑没有路径时使用下载归档，自动归档默认关闭。
- 云端包含账户删除后的本地归档，前提是本地归档仍保留。删除本机平台账号不会自动删除云恢复点。

## 运维与灾难恢复

私有 R2 前缀 `v1/客户数字ID/内容SHA256` 保存内容分块；`v1/客户数字ID/snapshots/UUID.json` 保存可独立恢复的完整恢复点索引。因此索引也在 R2，未单独依赖服务器本地 manifest。正常跨电脑恢复通过已认证的 API，客户不能指定其他客户前缀。

服务器 SQLite（含租户/配套与索引目录）仍需保留既有每小时备份并增加异地备份；目前系统定时数据库快照与服务器在同机。服务器丢失时，先恢复最新的 licensing DB，核对用户 ID 与 R2 所有权，再由管理员从对应私有 snapshots 前缀重建缺失目录，禁止按未经核对的用户名分配数据。

验证：`node scripts/test-cloud-backup.cjs` 与 `node scripts/test-translation-shortcut.cjs`。前者使用隔离假资料和内存对象仓库，不触及真实聊天或真实客户。
