                      AI 使用方式
                      Claude API Key
                      选择「自己的 Claude Key」时使用这里保存的 Key。切换到黑猫点数不会删除 Key。Key 加密保存在本机，可到 console.anthropic.com 申请。
                      
    
                      系统设置
                      弹窗显示发送者和消息开头；关闭后只显示“收到新消息”。锁屏时也会显示，注意隐私。
                      消息铃声总开关；每个账号可在环境设置中独立开关。聊天语音和视频不受影响。
                      调整所有账号的聊天网页大小，软件侧栏保持原来的尺寸。
                      清理超过6个月的翻译缓存数据翻译缓存仅在运行期间保存，退出软件后自动清空。
                      清理客户端网页缓存保留登录状态、账号、知识库和本地聊天备份。
                      平台设置
                      自定义左栏平台显示，拖动卡片可调整顺序。已添加的账号和登录数据会保留。
                      
    
                      软件运行时执行；新增内容持续归档，每小时扫描可读取历史并更新本地浏览记录。附件按内容去重，不重复复制同一文件。
                      每个账号一个 .blackcat 文件，包含该账号全部已备份的客户对话、消息和附件，可在黑猫中打开查看。
                      备份范围：软件实际读取到的记录和可下载附件。未加载的旧历史、网页预览图、未下载的原始视频不能保证完整；请补充平台官方导出的历史文件夹。
